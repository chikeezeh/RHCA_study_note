#### More filters example.

##### `map` filter.
The `map` filter is used to look up an attribute. The `map` filter returns a list by default, to see as a single line, incorporate the `join` filter.

Use case, if the `find` module is used to find files, multiple attributes are shown, and the `map` filter can be used to filter to just one attribute.

Example use case below, we found all the files in the `/etc/httpd` directory, however the output of the find command isn't useful in its raw state, with `map` and `list` we can convert to a more useful form by filtering out the file `path`.

```yaml
---
- name: showing map
  hosts: vm2
  gather_facts: no
  ignore_errors: true
  vars:
    basedir: /etc/httpd
  tasks:
  - name: showing files in basedir
    find:
      paths: "{{ basedir }}"
      recurse: yes
      depth: 4
    register: basedir_files
  - name: showing current variable contents to understand why we need map
    debug:
      var: basedir_files
  - name: show files based on map attribute with list
    set_fact:
      webfileslist: "{{ basedir_files['files'] | map(attribute='path') | list }}"
  - debug:
      var: webfileslist
  - name: now that we know that the list filter is mandatory, show relative file name
    set_fact:
      webfilesrelative: "{{ webfileslist | map('relpath', basedir) | list }}"
  - debug:
      var: webfilesrelative

```
